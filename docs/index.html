计算口径与说明

两种口径的差值（对每个进球数 0~7+球）：
· 口径A（多选优化保底）：优化赔率 = 1 ÷ Σ(1/该进球数每个比分的赔率)——把 1 元按赔率倒数比例拆注押该进球数的所有比分，无论哪个比分命中，保底回报就是优化赔率（1球时即 6.40×10.50÷(6.40+10.50) 这类公式）；差值A = 总进球赔率 − 优化赔率。
· 口径B（简单平均，仅记录对照）：平均赔率 = 该进球数各比分赔率的算术平均；差值B = 总进球赔率 − 平均赔率。由于平均赔率随比分个数放大，B 的差值不可跨档比较，不产出基线预测，仅保留差值记录与"模型B"学习用于对照。
· 7+球口径：竞彩比分矩阵只列到 5:2 / 2:5（总进球≥7 仅此两格），真正的 6:0、4:3、6:1 等都在「胜其他/平其他/负其他」三档里——7+球 = 矩阵≥7 的格子 ∪ 其他三档；缺其他档时不参与预测。

0球只有 0:0 一个比分，无法优化/平均 → 没有差值；其差值由全进球数二次曲线拟合给出（用 1~7+球的真实差值外推，不按 0 硬填），在差值概览中以 0* 标注。

预测双轨：基线 = 差值最小的进球数（0球用拟合值参与比较）；模型A（多因子·自修正） = 排名因子（近30天"差值排名 × 进球数"命中率，报冷场次不学习）⊕ 联赛因子（联赛历史进球分布）⊕ 球队因子（两队攻防强度泊松合成），按各因子近期实盘表现自学习权重加权融合——因子单独命中率需高出"基础命中率"2 个百分点以上才开始获得权重（12 个百分点封顶），达不到的自动休眠、权重≈0，不干扰差值信号。每场预测在封盘/结算时冻结（只用该场之前的数据，杜绝未来数据泄漏），双轨同场对比；模型B（相对差值口径）作为对照。

生效范围：新功能需要快照携带完整比分矩阵——仅对升级后抓取的场次生效（旧快照只有1球数据，显示为空）。每天 11:00 / 17:00 定时抓取，赛果与预测随之自动更新。

数据来自中国体育彩票官方接口。仅为个人数据分析用途，数据版权归中国体育彩票（sporttery.cn）所有，不构成投注建议，请理性购彩。
