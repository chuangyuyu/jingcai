计算口径与说明

优化赔率 = 1:0赔率 × 0:1赔率 ÷ (1:0赔率 + 0:1赔率)。含义：把 1 元本金按赔率倒数比例拆成两注分别押 1:0 和 0:1，无论哪个比分命中，回报都相同，这个保底回报就是优化赔率。

差值 = 1球赔率 − 优化赔率。正数表示押「总进球 1球」回报更高；负数表示押「1:0 + 0:1 比分双选（等回报拆注）」回报更高。1球赔率与比分双选对应同一个事件（全场恰好进 1 球）。

两次抓取：每天 11:00 与 17:00 各抓一次，①/② 列分别是第一、第二次抓取时的数据；变化列 = 第二次差值相对第一次：↑变大、↓缩小、→基本不变（±0.03）。第二次抓取时已开赛/停售的比赛只保留第一次数据。分析口径统一取最新一次快照。

单关维度：「单场胜平负」= 官方开放胜平负单关的场次（精挑细选），统计页可单独对比；勾选「只看单关」可将全部图表切换为单关视角。

数据来自中国体育彩票官方接口，每天定时抓取（本机任务）或手动抓取（本页按钮）；赛果于比赛结束后回填。

仅为个人数据分析用途，数据版权归中国体育彩票（sporttery.cn）所有，不构成投注建议，请理性购彩。
